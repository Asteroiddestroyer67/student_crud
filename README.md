# Student Record Management System
A simple, fully functional web-based CRUD application built with **PHP + MySQL** for XAMPP.
Demonstrates complete data flow: `Form → Controller → Database → Result` with soft-delete (archive & restore).

---

## ✨ Features
- **Create** — Add new student records (Student ID, Name, Program)
- **Read** — Display active records in table
- **Update** — Edit existing records
- **Archive/Soft Delete** — Mark as deleted without permanent removal
- **Restore** — Bring back archived records
- Success/error feedback messages
- Clean, responsive styling
